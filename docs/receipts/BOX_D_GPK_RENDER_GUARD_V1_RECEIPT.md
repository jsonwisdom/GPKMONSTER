## Guard position

Box D sits in front of canon/promotion and also performs readback after rendering:

```text
Receipt Ricky
  -> Box D preflight
  -> Renderer
  -> Box D readback
  -> Canon Carrie
  -> Lore Larry
  -> Press Patty
```

Correction lane:

```text
DELTA
  -> Override Ollie
  -> Renderer
  -> Box D readback again
```

Failed artifacts are not silently replaced. Each correction remains a distinct append-only object.
