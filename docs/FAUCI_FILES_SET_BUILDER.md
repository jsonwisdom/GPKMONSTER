## Workflow

1. **AL render** builds six deterministic SVG card images twice and rejects byte drift.
2. **ALMS machine law** validates evidence boundaries and identity metadata in parallel.
3. **Machine-to-Shopify adapter** converts validated inputs into a six-product draft handoff.
4. **Human judgment** uses the protected GitHub environment `gpk-human-judgment`.
5. **Shopify output** requires a second protected environment, `shopify-production`, plus store secrets.

Rendered images prove that the declared card inputs rendered successfully. They do not prove criminal allegations, legal equivalence, DOJ action, Senate certification, or court outcomes.
