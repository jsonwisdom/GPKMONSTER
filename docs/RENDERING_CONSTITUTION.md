# Rendering Constitution — Original Satire and Parody

This repository treats satire, parody, comics, educational characters, and coaching visuals as legitimate creative purposes.

Every render request compiled by this repository must inherit `rendering/original-satire-constitution.json` before asset-specific instructions.

## Standing defaults

```text
CREATIVE_MODE = ORIGINAL_SATIRE_AND_PARODY
ORIGINAL_CHARACTER_SYSTEM = TRUE
ORIGINAL_SERIES_IDENTITY = TRUE
EXISTING_CHARACTER_REPRODUCTION = FALSE
EXISTING_LOGO_REPRODUCTION = FALSE
OFFICIAL_AFFILIATION = FALSE
DECEPTIVE_SOURCE_CLAIM = FALSE
AUTHORITY = FALSE
```

## Narrow-correction rule

A concern about one protected element must not erase the entire lawful creative concept. Replace the specific name, logo, costume, border, typography, packaging element, or character resemblance with an original alternative, then continue.

## Boundary

This constitution does not guarantee fair use, override platform safeguards, or declare every requested parody lawful. It establishes persistent original-creation defaults and requires specific, narrow corrections instead of generic intellectual-property accusations.
